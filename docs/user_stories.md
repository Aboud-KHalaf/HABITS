# User Stories — HABITS

## 1. Habit Dashboard
As a **user**, I want to see today's habits with a clear split between pending and completed items so that I can quickly focus on what still needs to be done.

## 2. Quick Completion
As a **user**, I want to tap a habit to mark it complete and see instant visual feedback (strike-through, state change) so that tracking feels fast and satisfying.

## 3. Habit Creation
As a **user**, I want to create a habit with a name, icon, and optional notes so that I can define exactly what behaviour I want to track.

## 4. Flexible Scheduling
As a **user**, I want to set a habit as daily or on specific days of the week so that the app matches my routine rather than forcing a fixed schedule.

## 5. Reminders
As a **user**, I want to set an optional reminder time on a habit and receive a local notification so that I don't forget to complete it.

## 6. Streak Tracking
As a **user**, I want to see my current streak and all-time best streak for each habit so that I stay motivated by my consistency.

## 7. 90-Day Heatmap
As a **user**, I want a GitHub-style heatmap that shows my daily habit completion over the last 90 days so that I can visually spot patterns and gaps.

## 8. Calendar History
As a **user**, I want to browse past months on a calendar and inspect which habits were completed on any given day so that I can audit my long-term progress.

## 9. Data Export
As a **user**, I want to export my habit data as PDF or Excel so that I can share it or analyse it outside the app.
